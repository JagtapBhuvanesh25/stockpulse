# StockPulse — AI Inventory & Dynamic Pricing Engine

> Reactive commerce advisor: **inventory/demand signal → AI recommendation (price + reorder) → human approval.**

---

## Prerequisites

Make sure you have these installed before starting:

| Tool | Version | Check |
|---|---|---|
| **Node.js** | 18 or higher | `node --version` |
| **npm** | 8 or higher | `npm --version` |
| **Git** | any | `git --version` |

> **No database install needed** — uses SQLite (file-based, included).

---

## Setup Guide (< 5 minutes)

### 1. Clone the repo

```bash
git clone https://github.com/JagtapBhuvanesh25/stockpulse.git
cd stockpulse
```

---

### 2. Backend setup

```bash
cd backend

# Copy environment file
cp .env.example .env        # Mac/Linux
copy .env.example .env      # Windows
```

Open `backend/.env` and optionally add a Gemini API key:
```env
LLM_API_KEY=your-key-here   # Get free key at https://aistudio.google.com/apikey
                             # Leave blank — works without it (rule-based fallback)
```

Then install and start:
```bash
npm install
npx prisma migrate dev --name init    # creates the SQLite database
node prisma/seed.js                   # seeds 8 products + config
node src/server.js                    # starts on http://localhost:4000
```

Verify it works: http://localhost:4000/health → should return `{"ok":true}`

---

### 3. Frontend setup (new terminal)

```bash
cd frontend
npm install
```

**Start the dev server:**

```bash
# Mac / Linux
npx vite --port 5173

# Windows (if npx is blocked by PowerShell)
node node_modules/vite/bin/vite.js --port 5173
```

Open **http://localhost:5173** → StockPulse console loads with 8 seeded products.

## Environment Variables (`backend/.env`)

| Variable | Default | Description |
|---|---|---|
| `PORT` | `4000` | Backend port |
| `DATABASE_URL` | `file:./dev.db` | SQLite file path |
| `LLM_PROVIDER` | `gemini` | `gemini` \| `groq` \| `ollama` |
| `LLM_API_KEY` | *(blank)* | API key — leave blank for rule-only mode |
| `LLM_MODEL` | `gemini-1.5-flash` | Model name for your provider |
| `AI_TIMEOUT_MS` | `8000` | LLM call timeout in milliseconds |
| `PRICING_STRATEGY` | `rule` | Default strategy: `rule` or `ai` |
| `REORDER_STRATEGY` | `rule` | Default strategy: `rule` or `ai` |
| `SPIKE_MULTIPLIER` | `3` | Velocity spike threshold multiplier |

> **No API key?** All features still work — suggestions are generated by the rule engine and labeled `source: RULE_FALLBACK`.

## Demo Walkthrough

### Auto-trigger path (inventory low)
1. Open console → find **PRD-003 (Organic Cotton T-Shirt)** — stock 8, threshold 15
2. Click **▼** to expand → click **🛒 Sale**
3. Within ~2 seconds: pricing + reorder suggestion cards appear with `📉 Inv Low` badge
4. Click **✓ Accept** on pricing → price updates live in the table

### Demand spike path
1. Find **PRD-008 (Hoodie — Heather Grey)** — velocity 15
2. Click **🛒 Sale** 7 times → velocity crosses 3× peer average → `🔥 Spike` cards appear

### Strategy switching
1. Toggle **Pricing** from `≡ Rule` → `✦ AI` in the navbar
2. Trigger a suggestion → see `source: AI` (or `⟲ Fallback` if no key)

### AI streaming
1. Expand any product → click **✦ AI Stream**
2. Watch token-by-token reasoning appear in the terminal-style box

## Troubleshooting

| Problem | Fix |
|---|---|
| `npx vite` blocked on Windows | Use `node node_modules/vite/bin/vite.js --port 5173` |
| `EADDRINUSE: port 4000` | Another process using port 4000 — kill it or change `PORT` in `.env` |
| Blank white/black screen | Open browser DevTools → Console tab → report the error |
| `prisma migrate` fails | Delete `backend/prisma/dev.db` and retry |
| Suggestions not appearing | Wait 2–3 seconds (agentic loop is async); check backend terminal for `[RecommendationHandler]` logs |
| All suggestions show `RULE_FALLBACK` | No API key set — add `LLM_API_KEY` to `.env` and restart backend |

## Stack

| Layer | Technology |
|---|---|
| Backend | Node.js 18+ / Express / Prisma / SQLite |
| Frontend | React 18 / Vite / Vanilla CSS |
| AI | Gemini 1.5 Flash (Groq / Ollama also supported) |
| Strategy pattern | `CommerceStrategy` interface → `RuleStrategy` / `AiStrategy` |
| Agentic loop | Node `EventEmitter` + `setImmediate` (non-blocking) |

See [`ADR-0`](ADR.md) for the rationale behind choosing this stack over Spring Boot.
